Retail Sales Analysis Project

Project Overview

This project analyzes retail sales data to identify sales trends, customer behavior, product performance, and business insights.

Dataset

- Total Records: 1,500
- Data Type: Retail Sales
- Format: CSV

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Key Analysis

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales and Profit Analysis
- Monthly Sales Trend
- Category-wise Analysis
- Region-wise Analysis
- Customer Segmentation (RFM)
- Outlier Detection
- Business Insights

Project Outputs

- Cleaned Dataset
- Customer Summary
- Category Profit Analysis
- Dashboard KPIs
- Sales Charts
- Final Project Report

Conclusion

This project helps understand retail sales performance and provides useful insights for better business decisions.
